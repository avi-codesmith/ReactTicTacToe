# ❌ vs ⭕️ Tic Tac Toe Game⚡

A simple and interactive **Tic Tac Toe** game built to practice core programming concepts and UI logic. This project demonstrates clean game logic, state management, and a user-friendly interface.
---

## [Live demo](https://reactjavascript-tictactoe.netlify.app/)

---

## 💡Features

* Two-player gameplay (X vs O)
* Interactive React UI
* Displays winner or draw result
* Restart / reset game functionality
* Clean and easy-to-understand code structure

## 🎯 Game Rules

* The game is played on a 3×3 grid.
* Player **X** goes first, followed by Player **O**.
* The first player to get 3 marks in a row (horizontal, vertical, or diagonal) wins.
* If all cells are filled and no player wins, the game ends in a draw.
